01 · START FROM YOUR CODE

เลือก Raw HTML แล้วให้ Studio แยกส่วน

เลือกตัวอย่างจาก dropdown หมวดและรายการโค้ด ระบบจะแบ่ง HTML ตาม element หลักให้แก้เป็นส่วน ๆ ได้ ส่วน Quick Edit ใช้เปลี่ยนข้อความและ URL รูป ส่วนตัวเลือกสีมีทั้ง color picker, ช่องโค้ดสี และแถบ opacity พร้อมพรีวิวการ์ดทันที

ช่อง “ข้อความที่จะใส่เป็นช่อง $1” เลือกเนื้อหาที่เปลี่ยนตามคำตอบ Studio เลือกข้อความที่น่าจะเป็นเนื้อหาหลักให้อัตโนมัติ และสร้าง Style tag template จาก Raw HTML ทั้งก้อน

พื้นหลังเริ่มต้นถูกใส่ใน element หลักของการ์ด และถูกแยกเข้า CSS ที่สร้างให้ ไม่ได้ใส่บนพื้นหลังหน้าพรีวิว

02 · STYLE TAG

แยก HTML ต้นฉบับกับ HTML แม่แบบ

แท็บ HTML แม่แบบ (Style tag) คือโครงสร้างการ์ดที่แยก inline style เป็น class แล้ว แทนข้อความที่เลือกด้วย $1 หนึ่งจุด

แท็บ HTML ต้นฉบับ คือ Raw HTML เดิมที่ยังมี inline style อยู่ ใช้เทียบกับแม่แบบได้ ส่วน CSS ที่ดึงออกมาจะอยู่ในแท็บ CSS ส่วนกลาง

ชื่อแท็กแก้ได้ใน Quick Edit เช่น rubii21 ส่วนแท็บ ข้อความทดสอบ (Output) แสดงค่าทดลองในแท็ก เพื่อเห็นลำดับและรูปแบบข้อมูลที่ต้องส่งเข้า

ข้อความทดสอบก่อนแปลง<rubii21>ฝนเพิ่งหยุดตก Mira มองไปยังชานชาลา</rubii21>

03 · GLOBAL CSS

CSS ส่วนกลางถูกดึงจาก inline style

แท็บ CSS ส่วนกลาง รวมกฎจาก style="…" ของทุก element ให้เป็น class selector พร้อมใส่ class ที่ตรงกันไว้ใน HTML แม่แบบ การแก้สี พื้นหลัง หรือส่วนย่อยจะสร้าง CSS ใหม่ตามการแก้ไข

ใช้ CSS ที่ Studio สร้างได้เลย ไม่ต้องคัดกฎออกจาก HTML เอง และไม่ต้องใส่แท็ก <style> ครอบ

04 · REGEX

Regex แทนค่าได้หลายจุด และเพิ่มกฎแยกกันได้

Style tag ใช้ช่อง $1 เดียวตามตำแหน่งที่เลือก ส่วน Regex เลือกข้อความได้สูงสุด 33 จุด แล้วสร้าง capture group $1 ถึง $33 ใน HTML replacement ให้อัตโนมัติ หรือกดเพิ่มกฎ Regex เพื่อกำหนด pattern/replacement เอง

ระบบเลือก marker เช่น (ข้อความที่เปลี่ยน) หรือ {{field}} ให้อัตโนมัติ หากต้นฉบับเป็นข้อความตัวอย่างธรรมดาให้ติ๊กเลือกทีละจุดเอง เพราะ Studio บอกไม่ได้ว่าค่านั้นจะเปลี่ยนตอนใช้งานจริงหรือไม่

เมื่อเลือก 3 จุดใน Quick Edit<tag>ชื่อโพสต์||จำนวนไลก์||คอมเมนต์</tag>

Regex หลายช่องใช้ || คั่นค่าตามลำดับที่เลือก ห้ามมี || อยู่ในค่าจริงของช่องนั้น ๆ เพิ่ม Regex แยกได้หลายกฎ พร้อมตั้งชื่อ เลือกให้ทำงานกับเนื้อหาต้นฉบับหรือข้อความที่แสดง และแก้ pattern/replacement ได้

เนื้อหาต้นฉบับ

มองเห็นข้อความดิบ รวม Markdown, HTML, attribute และ CSS เหมาะกับการแทน marker หรือโครงสร้างทั้งก้อน กฎทำงานก่อนขยาย Style tag

ข้อความที่แสดง

ทำงานหลังขยาย Style tag และจัดรูปแบบ Markdown แล้ว เปลี่ยนเฉพาะข้อความที่เห็น ไม่แก้ HTML tag หรือ CSS

นิพจน์ใช้รูปแบบ /pattern/flags โดย $1 ถึง $33 ใน replacement อ้างถึง capture group ตามลำดับ กฎ Regex ใน Rubii ทำงานตามลำดับที่ตั้งไว้ ส่วน Regex กับ Style tag เป็นวิธีแทนแท็กคนละแบบ ควรเลือกอย่างใดอย่างหนึ่งสำหรับแท็กเดียวกัน

05 · GENERATED OUTPUT

ข้อความทดสอบและคำสั่งตัวละคร

ข้อความทดสอบ (Output) คือข้อความต้นทางที่โมเดลส่งในแชตก่อน Rubii แปลงเป็นการ์ด ระบบเติมค่าทดสอบที่อ่านได้ให้แล้ว: marker ใช้ค่าตัวอย่างตามชนิด ส่วนข้อความคงที่ใช้ข้อความจาก HTML ที่เลือก แทนค่าทดสอบด้วยข้อมูลจริงก่อนใช้งาน และคั่นหลายช่องด้วย ||

ตั้งค่าตัวละคร · System Prompt เป็น Markdown แบบหัวข้อและ bullet สั้น ๆ บอกว่าจะใช้แท็กเมื่อใด ใส่ข้อมูลอะไร และเรียงช่อง Regex อย่างไร โดยไม่สั่งให้เขียน HTML/CSS

ข้อความนี้เป็นคำสั่งธรรมดาสำหรับต่อท้าย System Prompt ของตัวละคร ไม่ใช่ JSON หรือไฟล์นำเข้า และจะเปลี่ยนตามชื่อแท็กกับช่องข้อมูลที่เลือก

Rubii ประมวลผล Regex ในเนื้อหาต้นฉบับก่อนขยาย Style tag และ Markdown จากนั้นจึงทำ Regex ในข้อความที่แสดงและใช้ CSS ส่วนกลาง ดูลำดับนี้ประกอบก่อนเลือกใช้ Regex กับ Style tag พร้อมกัน

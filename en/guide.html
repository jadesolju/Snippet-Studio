RAW HTML → RUBII CONFIG

Turn code into a Rubii setup

Choose a library snippet and Studio will show its HTML template, raw HTML, Global CSS, Regex, test text, and System Prompt in separate tabs. You can adjust the tag name and replacement fields in one place.

01 · START FROM YOUR CODE

Choose Raw HTML and let Studio split it into sections

Choose an example from the category and snippet dropdowns. Studio splits the HTML by its main elements so you can edit each part. Quick Edit changes text and image URLs. Color controls include a picker, a color-code field, and an opacity slider, with an instant card preview.

The “Text to insert as $1” field selects content that changes with the reply. Studio automatically chooses the most likely main content and creates a Style tag template from the full Raw HTML.

The configured background is applied to the main element and moved into the generated Global CSS. The preview runs in a browser iframe, so it confirms browser rendering only.

02 · STYLE TAG

Separate Raw HTML from the HTML template

tab. HTML template (Style tag) This is the card structure with inline styles converted to classes. The selected text is replaced with $1 one value.

tab. Raw HTML This is the original Raw HTML with inline styles intact, for comparison with the template. Extracted CSS appears in the Global CSS

You can change the tag name in Quick Edit, for example rubii21 The Test text (Output) shows sample values inside the tag so you can see the order and format of the required input.

Test text before conversion<rubii21>The rain has just stopped. Mira looks toward the platform.</rubii21>

03 · GLOBAL CSS

Global CSS is extracted from inline styles

tab. Global CSS combines rules from style="…" on every element into class selectors and adds the matching classes to the HTML template. Editing colors, backgrounds, or sections generates updated CSS. For an image or GIF, use <img src="…" alt="…" class="my-gif"> and set its size in CSS.

In Rubii, paste the generated rules into Global CSS and use selectors that match the classes in the HTML template. Do not wrap them in a <style> to wrap site-wide CSS, such as body or site-specific classes, which may not exist in chat messages. Update the selector to target an element in the card.

The CSS extractor reads only inline style="…" in the HTML created by Studio. It does not extract CSS from the source site, <link rel="stylesheet"> or <style> blocks. If you edit CSS in the code field, it becomes a manual override. The preview may still show the HTML background, but copied CSS may omit that rule; it will not be regenerated automatically after background or Quick Edit changes.

04 · REGEX

Regex can replace multiple values, and you can add separate rules

A Style tag uses the $1 field at the selected position. Regex can select up to 33 text values and automatically creates capture groups $1 through $33 in the HTML replacement, or add a Regex rule and define the pattern and replacement yourself.

Studio automatically detects markers such as (changing text) or {{field}} automatically. If the source contains ordinary sample text, select each value manually because Studio cannot tell whether it will change in actual use. Repeated identical markers, such as (HH:MM) use one capture for every occurrence. Give markers different names when the values should be separate. Meanwhile, {{user}} and {{char}} remain Rubii macros and do not count as captures.

Parentheses define exactly which text will be replaced: a lovely restaurant near 📍 (a location) captures only the location, while (a lovely restaurant near 📍 a location) captures the full phrase as $1 Nested parentheses are not supported. If a phrase already contains parentheses, use a marker such as {{restaurant_query}} instead.

When you select 3 fields in Quick Edit<tag>post title||like count||comment</tag>

For multiple Regex fields, use || to separate values in selection order. Do not include || inside an actual field value. A percentage field captures only the number and accepts a trailing % . The replacement then adds % to the text and status bar.

You can add and name multiple Regex rules, choose whether each works on the source or displayed text, and edit its pattern and replacement. The alternate-format button copies the main Regex replacement and creates a pattern for the selected delimiter |, comma, or newline. Use each rule for a different source format; every rule should produce a complete output.

Source content

Works on raw text, including Markdown, HTML, attributes, and CSS. Use it to replace markers or larger structures. These rules run before Style tags are expanded.

Displayed text

Runs after Style tags are expanded and Markdown is formatted. It changes visible text only; HTML tags and CSS are unchanged.

Use this expression format /pattern/flags where $1 through $33 in the replacement refers to the capture group in order. Rubii runs Regex rules in their configured order. Regex and Style tags are separate ways to replace a tag, so choose one method for each tag.

05 · GENERATED OUTPUT

Test text and character instructions

Output shows only the value the model places in a tag before conversion, not a finished card. For example, selecting {{user}} you may see only <cozy-room>you</cozy-room>

Test text (Output) is the source text the model sends in chat before Rubii turns it into a card. Studio fills in readable sample values: markers use examples for their type, while fixed text uses the selected HTML text. Replace the samples with real data before use, and separate multiple values with ||

Character setup · System Prompt is Markdown with short headings and bullets describing when to use the tag, what data to include, and the order of Regex fields. It does not instruct the character to write HTML or CSS.

This is plain text to append to a character's System Prompt, not JSON or an import file. It updates based on the selected tag name and data fields.

Rubii applies Regex to source content before expanding Style tags and Markdown. It then applies Regex to displayed text and uses Global CSS. Keep this order in mind when combining Regex and Style tags.

Rubii says Style Tags and Global CSS are supported on the web and in app version 2.4.2 and later, and recommends checking both platforms. Studio's browser-iframe preview does not confirm how a card will behave in the mobile app.

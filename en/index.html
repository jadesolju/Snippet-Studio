Explicit markers are selected automatically. Values that may change, such as dates, times, amounts, stats, reference IDs, or prompts, are labeled “Review” so you can select them after confirming they should change. Other text is labeled “Example”, and the system captures values in order as $1 through $33 Macro {{user}} and {{char}} remain Rubii macros and are not counted as captures

Parentheses mark the value to replace: (location) replaces only the location, while (a lovely restaurant near a location) replaces the entire phrase. The parentheses must enclose the full value you want to replace.

When you select multiple fields, separate their values in the tag with || for example, <tag>post title||like count</tag> Percentage fields capture only the number and accept a trailing % after it. Repeated markers such as (HH:MM) use $ one capture for every occurrence. To capture them separately, use different marker names.
